## Getting Started
1. Rename a `### Phase N: [Name]` heading above — a bracketed `[Name]` is a
   placeholder and is not a phase until it has a real title
   (`tagteam roadmap check` lists the ones left).
2. `tagteam roadmap ready` shows the phases that can start now.
3. The lead opens a phase's plan cycle with `/tagteam:handoff start [phase]`
   (any agent with a shell: read `tagteam contract`).
4. `/tagteam:handoff status` (or `tagteam state`) shows whose turn it is.
